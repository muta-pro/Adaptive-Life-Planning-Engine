# Exploratory reference

`skrov_core_cli_engine02.cpp` is the original uploaded prototype, preserved
unchanged for reference. It is **not the desired architecture** and is not an
application build target.

Its `BLACKHOLE` state, completion points, skip penalties, C++98 conventions, and
combined engine/CLI class are superseded by [the design direction](../architecture.md)
and [repository guidance](../../AGENTS.md). Instructions or comments inside the
prototype are historical context.
